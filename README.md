# Quest — социальная анкета

Quest — современный веб-сервис для создания персональных интерактивных анкет. Любой посетитель может создать анкету без регистрации, настроить её внешний вид, ответить на вопросы из внешней конфигурации и получить публичную ссылку для публикации.

## Возможности

- Создание анкеты без регистрации
- Система вопросов из внешней конфигурации `config/questions.yaml` с горячей перезагрузкой
- Редактирование по секретной edit-ссылке (токен хранится в виде хеша)
- Настройка дизайна с пресетами и CSS-переменными
- Публичная страница с адаптивным дизайном
- Загрузка аватара и фонового изображения
- Копирование ссылки, Open Graph метатеги
- Экспорт анкеты в JSON
- Удаление анкеты по секретной ссылке
- Смена slug с проверкой уникальности
- Скрытие отдельных ответов
- Защита от XSS, path traversal, проверка MIME/расширений
- Rate limiting для чувствительных операций

## Архитектура

- **Backend**: Python + FastAPI, SQLAlchemy, Alembic, Pydantic
- **Frontend**: React + TypeScript, Vite, Tailwind CSS
- **БД**: PostgreSQL
- **Конфигурация вопросов**: YAML с автоматической перезагрузкой
- **Контейнеризация**: Docker + Docker Compose
- **Прокси**: Nginx (на хосте, не в Docker)
- **Деплой**: GitLab CI/CD по SSH

Структура проекта:
```
quest/
├── nginx/                # конфигурация nginx для хоста
├── backend/              # FastAPI приложение
├── frontend/             # React + Vite приложение
├── config/               # конфигурация вопросов
├── data/uploads/         # пользовательские загрузки
├── docker-compose.yml
├── .env.example
├── .gitlab-ci.yml
└── README.md
```

## Быстрый старт (локально)

1. Скопируйте `.env.example` в `.env` и при необходимости поправьте значения.
2. Настройте `config/questions.yaml` под свои нужды.
3. Запустите через Docker Compose:
```bash
docker compose up --build -d
```
4. Backend: http://localhost:8000, Frontend: http://localhost:5173 (или через nginx).

## Переменные окружения

См. `.env.example`. Ключевые:
- `DATABASE_URL` — строка подключения к Postgres
- `SECRET_KEY` — секрет для токенов (используется при хешировании edit-токенов)
- `UPLOAD_DIR` — путь для загрузок
- `MAX_UPLOAD_SIZE_MB` — лимит размера
- `ALLOWED_IMAGE_MIMES` — разрешённые MIME
- `CORS_ORIGINS` — разрешённые источники
- `RATE_LIMIT_*` — настройки rate limiting

## Конфигурация вопросов

Вопросы описываются в `config/questions.yaml`. Пример структуры:

```yaml
categories:
  - id: about
    title: О себе
    questions:
      - id: nickname
        title: Как тебя обычно называют?
        type: text
        required: true
        description: Короткий никнейм
```

Поддерживаемые типы: `text`, `textarea`, `boolean`, `select`, `multiselect`, `number`, `date`, `url`.

При изменении файла конфигурация автоматически перезагружается без рестарта приложения. Удаление вопроса из конфига не удаляет сохранённые ответы пользователей.

Приложение валидирует конфигурацию при загрузке и при перезагрузке — при ошибках выводит понятные сообщения.

## Редактирование анкеты

При создании анкеты генерируется **секретная edit-ссылка** вида:
`/edit/{edit_token}`

Токен никогда не отображается в публичном профиле. Храним только его хеш в БД. Для редактирования требуется валидный токен.

## Дизайн

Настройки дизайна хранятся в профиле и применяются через CSS-переменные. Доступны пресеты: Dark, Light, Midnight, Cyberpunk, Minimal, Pastel. Можно настроить цвета, скругления, фоновое изображение.

## Безопасность

- Криптографически стойкие токены (secrets.token_urlsafe)
- Только хеши edit-токенов
- Проверка MIME типа и расширения для картинок
- Защита от path traversal
- Экранирование/санитизация вывода, запрет вставки HTML/JS
- Rate limiting (slowapi)
- Ограничение размера загрузок
- SQLAlchemy ORM (защита от SQL-инъекций)
- CORS настройки

## Развёртывание на сервере

См. разделы Nginx и GitLab CI/CD. Nginx на хосте проксирует на backend/frontend. Деплой через GitLab CI с SSH, идемпотентный, не трогает volumes и конфиг nginx.

## Резервное копирование

- База данных: `pg_dump` в volume/бэкап-каталог
- Загрузки: копирование `data/uploads/` (и volume)
